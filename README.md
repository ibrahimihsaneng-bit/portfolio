# Ibrahim Ihsan — Engineering Portfolio & ATS Resume Suite

Professional portfolio and ATS-optimized resume suite for **Ibrahim Ihsan** (Mechanical Engineering, TKM College of Engineering).

## 📁 Package Structure

* **`index.html`**: The complete, interactive single-page portfolio website featuring:
  * Clean, responsive dark aesthetic with discipline filter chips and modal lightbox inspection.
  * Verified engineering case studies across CAE simulation, freelance client contracts, financial operations, and 2D MEP automation.
  * Quantitative validation matrix comparing numerical solver results against analytical closed-form equations.
* **`resume.html`**: A pixel-perfect, single-page ATS-formatted resume designed for international job/internship applications. (Open in any browser and press `Ctrl + P` to save as a clean PDF).
* **`resume.md`**: Markdown version of the resume for fast pasting into online portals and GitHub profile READMEs.
* **`assets/images/`**: High-resolution FEA/CFD simulation contours, 3D stress tensors, and architectural system schematics.

---

## 🚀 How to Run Locally

1. Simply double-click **`index.html`** in your file manager to open it in Chrome, Edge, or Firefox.
2. Double-click **`resume.html`** and press **`Ctrl + P`** -> select **"Save as PDF"** to get your official application PDF.

---

## 🌐 Free 1-Click Deployment (Make it Live Online)

### Option A: GitHub Pages
1. Create a new GitHub repository named `portfolio`.
2. Push the files in this folder to the repository.
3. Go to **Settings > Pages > Branch: main / root** and click Save. Your site will be live at `https://<your-username>.github.io/portfolio`.

### Option B: Vercel / Netlify
1. Drag and drop this folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
2. It will deploy instantly with a free SSL domain.
